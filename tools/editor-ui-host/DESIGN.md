# Epidemic Islands Dark

Mode: Operate. The supplied Roadmap sketch and U_Phase tokens are visual authority. Main layout: left Project Explorer/Scene Hierarchy tab group, central Game/Scene/Graph/Code documents, contextual right primary/secondary groups, collapsed global bottom tools. Scene starts selected. Prefab Editor first docks at the right context wall. All future controls have phase/reason and are disabled until real backend wiring.

Theme.java owns palette and dimensions: purple-to-red branding limited to launcher/header, neutral dark tool/document surfaces, selection purple, primary/secondary/disabled text with readable contrast, panel radius 10, control radius 6, gap 6 and spacing unit 4. System Dialog font supports Cyrillic and is not redistributed. Native menus, keyboard, file picker, visible focus and heavyweight popup handling are functional requirements. Dense forms use one field-descriptor renderer; scroll/focus and component identity survive context changes and detach. Graph/Scene space stays quiet and data-oriented.

No JetBrains logos, fonts, icons or proprietary SDK assets are copied. Diagnostic viewport frames are explicitly marked as a shell pending F2 integration. Gallery values are UI samples; planned controls never masquerade as game state.
