# Ошибки, Result и инварианты

`foundation::Result<T>` описывает ожидаемые recoverable failures: невозможность создать окно, загрузить payload, обработать данные или завершить транзакцию. Нарушение программного контракта (двойная регистрация сервиса, недопустимый lifecycle, цикл зависимостей) квалифицируется отдельно; assertions/exceptions не обязаны быть представлены как normal runtime failure.

Runtime coordinator различает fatal-level contract error `Tick()` и локальную recoverable ошибку major, включаемую в `RuntimeTickResult.failures`. После локальной ошибки независимые фазы продолжаются. Диагностику необходимо читать вместе с `executed_steps`, provenance и текущим lifecycle.

Для Auditor крайне важно различать `COMPLETE` захват, `PASS` проверку, `UNKNOWN` отсутствие измерения и `INCOMPLETE` утрату информации. [[08 Auditor/Понимание evidence]].
