# Создание нового модуля

Сначала классифицируйте: Base foundation, нейтральный Runtime major, GameplayWorldStateOwner либо IntegrationLayer adapter. Примерный маршрут:

1. Определить contract: IDs, methods/ports, authority, errors, concurrency, lifetime, persistence и deterministic behavior.
2. Добавить отдельный public header в `include/Epidemic/...`, source в `src/`, тесты в соответствующее семейство.
3. Создать/изменить module `CMakeLists.txt` с верным `PUBLIC/PRIVATE/INTERFACE` согласно реально используемым публичным include.
4. Зарегистрировать подкаталог в верхнем CMake, если выбранная архитектура допускает новый production module.
5. Подключать между majors только разрешёнными adapters и без duplicate owner state.
6. Добавить positive/negative тесты и обновить contract documentation.
7. Запустить architecture negative fixture, header self-containment, адресные и интеграционные тесты.

Новый Framework module не должен незаметно расширять существующую freeze allowlist. Решения о новых целевых модулях требуют отдельного архитектурного изменения, доказательства и обновления диаграмм зависимостей. [[02 Архитектура/Правила архитектурного freeze]].
