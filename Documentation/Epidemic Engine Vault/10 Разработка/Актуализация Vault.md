# Поддержка документации при изменении кода

Этот Vault является **снимком** конкретного архива и не отслеживает файлы на диске автоматически. Чтобы сохранить соответствие:

1. Зафиксируйте commit, uncommitted changes и дату получения исходников.
2. Выполните `cmake`/CTest и не переносите старые verdict на новый tree.
3. Замените исходную документацию в `90 Первоисточники/`, затем пересоберите каталоги публичных headers и module cards из нового кода.
4. Проверьте, что новые `[[wikilinks]]` разрешаются и `Mermaid` отражает CMake architecture graph.
5. Вручную проверьте страницы сценариев и статуса milestone после изменений контрактов.
6. Сохраните дату и SHA-256 исходного архива как provenance.

В папке `99 Служебное/` есть `manifest.json`, перечень прочитанных исходных документов и `check_vault.py`. Скрипт валидирует структуру `[[wikilinks]]`, но не заменяет сборку C++ или semantic review.
