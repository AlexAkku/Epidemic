# Среда инструментов и retrieval

Локальные инструменты находятся в `Development/AgentsRules/` (источники) и `.ai/` (временные outputs). Основные entrypoints:

| Скрипт | Назначение |
| --- | --- |
| `Scripts/Doctor.ps1` | Проверить инструменты и readiness |
| `Scripts/Setup-AgentTools.ps1` | Установить/развернуть pinned pipeline |
| `Scripts/Invoke-Dev.ps1` | Configure, Build, Test, Full по профилю |
| `Scripts/Run-Quiet.ps1` | Длинные команды с ресурсными лимитами, логами |
| `Scripts/Verify-Changed.ps1` | Адресная/static проверка изменений |
| `Scripts/Prepare-Clangd.ps1` | Подготовка индекса clangd |
| `Scripts/Run-ClangdMcp.ps1` | Интеграция clangd MCP |
| `Scripts/Search-Code.ps1` | Поиск по коду |
| `Retrieval/retrieve.py` | Семантическое извлечение по индексам |

Правила индексирования и reranking исходно описаны в `Development/AgentsRules/Retrieval/README.md`. Индекс может устаревать после изменения заголовков/символов, поэтому clangd semantics должны подтверждаться текущей compilation database.
