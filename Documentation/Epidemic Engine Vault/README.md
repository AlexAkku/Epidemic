# Epidemic Engine Obsidian Vault

Автономная документация исходного архива от 10 октября 2026 года.

1. Распакуйте каталог `Epidemic Engine Vault` в любое место на Windows.
2. В Obsidian выберите **Open folder as vault** и укажите эту папку.
3. Откройте `00 Главная.md`, затем `Карта движка.canvas` для визуального маршрута.
4. Используйте разделы `04`, `05`, `06` для модулей, `11 API` для полного текста публичных заголовков и `90 Первоисточники` для исходных документов.

Vault не содержит исполняемый движок. Исходный C++ проект нужен для сборки и изменений кода. CLI команды подразумевают PowerShell из корня исходников Epidemic.

Детали статуса, достоверности и проверки ссылок находятся в `09 Качество и статус/` и `99 Служебное/`.
