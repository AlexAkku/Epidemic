# Epidemic Engine Obsidian Vault

Автономная документация исходного архива от 10 октября 2026 года.

1. Распакуйте каталог `Epidemic Engine Vault` в любое место на Windows.
2. В Obsidian выберите **Open folder as vault** и укажите эту папку.
3. Откройте `00 Главная.md`, затем `Карта движка.canvas` для визуального маршрута.
4. Используйте разделы `04`, `05`, `06` для модулей, `11 API` для полного текста публичных заголовков и `90 Первоисточники` для исходных документов.

Vault не содержит исполняемый движок. Исходный C++ проект нужен для сборки и изменений кода. CLI команды подразумевают PowerShell из корня исходников Epidemic.

Детали статуса, достоверности и проверки ссылок находятся в `09 Качество и статус/` и `99 Служебное/`.

## Версия 1.1: углубление существующих страниц

Порядок каталогов и охват документации не изменены. На страницах модулей добавлены исходные контракты, инварианты, наборы операций, CMake-зависимости, диагностика с исходными строками, файлы реализации и тестовые якоря. На страницах API имеются сводки сигнатур, поля и состояния, правила использования и, где удаётся точно локализовать исходную позицию, ссылки на реализации и test call sites.

Разделы архитектуры и работы с движком расширены по существующим темам, включая практические примеры PowerShell и C++, failure/retry и порядок системных вызовов.

Карта вызовов извлечена из текста C++ консервативными правилами, она не является компиляторным AST: overloaded, nested, macro и platform-specific declarations сверяйте через clangd. Полные исходные заголовки не изменены. Источники `90 Первоисточники` не переписаны.

Сборка и тесты Windows в ходе создания версии 1.1 не выполнялись. Нельзя трактовать наличие тестового якоря как прошедший тест.
