# Матрица регрессий и квалификации

| Цель проверки | Команда / источник | Что фиксирует |
| --- | --- | --- |
| Архитектурный negative contract | `cmake -P cmake/ArchitectureFreezeSelfTest.cmake` | Отбрасывание запрещённых графов |
| Public header self-containment | `cmake --build build/full-debug --config Debug --target EpidemicPublicHeaderSelfContainment --parallel` | Самодостаточность include |
| Unit/integration engine | `ctest --test-dir build/full-debug -C Debug --output-on-failure --no-tests=error` | Фактические CTest результаты |
| Runtime адресная регрессия | `ctest ... -R EpidemicRuntime ...` | Только отфильтрованные Runtime тесты |
| Изменённые файлы | `Verify-Changed.ps1 -Mode Deep` | Встроенные статические проверки |
| Git whitespace | `git diff --check` | Проблемы патча |
| Квалификация по проектному pipeline | `Invoke-Dev.ps1 -Action Full -Profile full -Configuration Debug` | Clean + architecture + headers + tests + Deep |
| Auditor Python tests | `.epidemic-auditor/Self-Test.ps1` | Python unittest suite текущего файла |
| Auditor native физические profiles | Сборка и запуск профилей `audit`, `audit-deep`, `audit-memory`, `audit-coverage` | Scope-инструментирование, good/bad controls |

Тесты должны запускаться на одной зафиксированной версии исходников и с источниками evidence, содержащими toolchain, binary identity и exit codes. Не считайте успешный `cmake`/`ctest` доказательством всех требований безопасности, детерминизма и пользовательской игры.

## Какое доказательство необходимо для какого утверждения

| Заявление | Минимальная требуемая проверка | Чего она не подтверждает |
| --- | --- | --- |
| Локальная функция исправлена | Адресный тест на исправленный инвариант и негативный контроль | Все зависимости и соседние consumers |
| Публичный интерфейс совместим | Self-containment заголовков, компиляция consumers, relevant CTest | Runtime semantics в любой конфигурации |
| Нет запрещённой архитектурной связи | Architecture freeze negative/self-test и link/include checks | Отсутствие runtime behavioural bugs |
| Runtime Support не теряет ownership | Fault-injection + retry, repeated shutdown, integration test | Memory safety за пределами observation scope |
| Auditor run корректно разобран | Проверка raw capture, provenance, coverage/completeness и schema | Отсутствие ошибок в неохваченных событиях |
| Milestone закрыт | Полная заранее определённая acceptance matrix на зафиксированном tree | Будущие milestones и будущие реализации Game |

Сохраняйте проверку на конкретном source commit/dirty tree. Изменение входного бинарника, профиля инструментирования или ветки исходников делает предыдущее доказательство отдельным историческим run. За `PASS` конкретного fixture не следует статус всего Milestone.
