## Как проверять прочитанное

Для каждого major начните с `Обзор`, затем выберите один публичный интерфейс и проследите: declaration -> implementation -> expected error code -> test -> CMake target. Следующий шаг: найти cross-major adapter в Support и убедиться, что опубликованный state имеет единственного владельца. Этот подход важнее чтения сотен заголовков подряд.
