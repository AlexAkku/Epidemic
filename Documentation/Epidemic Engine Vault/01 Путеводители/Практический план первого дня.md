# Первый день разработки

1. Разместите исходный проект отдельно от Vault. Не распаковывайте документацию поверх исходников.
2. В PowerShell из корня репозитория выполните `git status --short` и сохраните список локальных изменений. Снимок из архива содержит рабочие изменения относительно `HEAD`.
3. Выполните `Development/AgentsRules/Scripts/Doctor.ps1` в настроенной среде PowerShell 7 и VS C++.
4. Если инструментов не хватает, воспользуйтесь `Setup-AgentTools.ps1` (предварительно оценив его системные установки).
5. Выполните адресную конфигурацию и сборку через `Invoke-Dev.ps1` или CMake Presets.
6. Выполните `ctest --test-dir ... -C Debug --output-on-failure --no-tests=error`.
7. Откройте [[03 Работа с движком/Smoke приложения]] и запустите базовый пример с корректным рабочим каталогом.
8. Прочитайте [[09 Качество и статус/Текущее состояние и границы достоверности]] и проверьте результат тестов именно на своей машине.

Изменения кода начинайте только после определения owner-модуля и допустимых зависимостей в [[10 Разработка/Как изменять движок]].
