# Что Vault включает и чего в нём нет

Этот комплект включает навигацию по слоям и технологиям, сборку/тестирование, практические data flows, справочник владельцев и контрактов модулей, Auditor, статус и полные текстовые снимки публичных `.h`. Отдельно включены исходные Markdown-документы репозитория.

В Vault **нет полной копии `.cpp`, бинарников, source-to-source links в редактор C++ или результатов нового Windows CI запуска**. Полный API нельзя вывести только из текстового анализа `.h`: overload resolution, macros, templated declarations и actual link требуют компилятора/clangd. Модульные card summaries являются навигационным уровнем, точные semantics определяют public contracts и tests.
