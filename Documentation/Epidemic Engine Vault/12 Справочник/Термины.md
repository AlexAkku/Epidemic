# Словарь основных терминов

| Термин | Значение |
| --- | --- |
| **Owner** | Единственный authoritative владелец заданного domain state |
| **Derived state** | Проекция, вычисляемая из authoritative данных |
| **Major** | Независимый функциональный модуль EngineRuntime |
| **Support** | Composition layer, соединяющий major ports типизированными adapters |
| **Port** | Публичный абстрактный interface для связи без concrete dependency |
| **Adapter** | Реализация сопряжения одного контракта с другим на разрешённой границе |
| **Lease** | Право/обязанность удерживать ресурс и закрывать lifetime |
| **Residency** | Присутствие chunk/ресурса в активном runtime |
| **Snapshot** | Согласованный с определённой границей immutable слепок состояния |
| **Checkpoint** | Точка восстановления с заданной областью и ограничениями |
| **Determinism** | Воспроизводимость результата при идентичных специфицированных input и state |
| **Provenance** | Источник доказательства (внешний OS, CTest, engine probe и т.д.) |
| **RunId** | Идентификатор исследованного запуска Auditor |
| **ActionId** | Идентификатор ограниченного сценария причинной корреляции |
| **Freeze** | Контракт границ и квалификация по установленным проверкам |

Детальный исходный двуязычный словарь находится в [[90 Первоисточники/Documentation/epidemic-terminology-dictionary|терминологическом словаре проекта]].

## Связь терминов с implementation contracts

Owner обозначает единственный authoritative state holder. Adapter связывает разные majors через типизированные ports без forbidden peer linking. Lease является обязательством сохранять ресурс до подтверждённого Release. Revision представляет версию конкретного owner. Snapshot является detached наблюдением или сохранением только если контракт прямо обещает durable semantics. `LOCAL_READY` относится к локальной квалификации; `FROZEN` требует дополнительных системных gates.
