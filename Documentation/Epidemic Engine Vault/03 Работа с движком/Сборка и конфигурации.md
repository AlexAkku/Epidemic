# Сборка и конфигурация

Корневой `CMakeLists.txt` требует CMake 3.25, задаёт C++23 и подключает EngineBase, опционально Runtime и Framework. Конфигурационные флаги извлечены из архива:

| CMake-переменная | По умолчанию | Смысл |
| --- | --- | --- |
| `BUILD_TESTING` | `ON` | Регистрация тестов |
| `EPIDEMIC_BUILD_RUNTIME` | `ON` | Включить Runtime |
| `EPIDEMIC_BUILD_FRAMEWORK` | `ON` | Включить Framework, требующий Runtime |
| `EPIDEMIC_WARNINGS_AS_ERRORS` | `OFF` | Ошибки компиляции при предупреждениях для owned targets |
| `EPIDEMIC_ARCHITECTURE_FREEZE_CHECKS` | `ON` | Архитектурные проверки |
| `EP_AUDITOR_PROFILE` | пусто | Инструментированный Auditor build |

### Рекомендуемый проектный pipeline

```powershell
# Запуск из корня исходного репозитория в PowerShell 7
.\Development\AgentsRules\Scripts\Invoke-Dev.ps1 -Action Configure -Profile full -Configuration Debug
.\Development\AgentsRules\Scripts\Invoke-Dev.ps1 -Action Build -Profile full -Configuration Debug
.\Development\AgentsRules\Scripts\Invoke-Dev.ps1 -Action Test -Profile full -Configuration Debug
```

`Invoke-Dev.ps1` использует `Visual Studio 18 2026`, платформу x64, WarningsAsErrors и отдельные `build/<profile>-<config>`. Он вызывает `Run-Quiet.ps1` для изоляции ресурсоёмких команд. Если у Вас установлен другой генератор, используйте обычный CMake после проверки локального toolchain. Генератор `Visual Studio 18 2026` потребуется только этому скрипту.

### Прямой CMake

```powershell
cmake -S . -B build/full-debug -A x64 -DBUILD_TESTING=ON
cmake --build build/full-debug --config Debug --parallel
```

`-A x64` корректен для Visual Studio generator, и его следует опустить с Ninja. Альтернатива: `cmake --preset full-debug`, затем `cmake --build --preset full-debug`, если текущий generator и конфигурация совместимы. Пресеты `base-debug`, `runtime-debug`, `full-debug` объявлены в `CMakePresets.json`, но не закрепляют generator.

### При изменении конфигурации

Не смешивайте Debug/Release, `EP_AUDITOR_PROFILE` и compiler в одной CMake build directory. Если был изменён toolchain, используйте отдельный `build/` каталог. Framework с `EPIDEMIC_BUILD_RUNTIME=OFF` является запрещённой конфигурацией и явно отклоняется.
