# Windows: окружение и требования

Основная целевая платформа снимка: Windows 11, x64, Win32, D3D11, C++23. Runtime/Auditor с MSVC native instrumentation зависят от Windows API. Поддержка macOS/Linux/Metal/Vulkan не подтверждена реализованными production backends данного снимка.

Для основной сборки нужны CMake ≥3.25, MSVC с C++23 и Windows SDK, корректная VS Developer Environment. Агентский pipeline дополнительно ожидает PowerShell 7 (`pwsh`), Git, Ninja, clangd, Python, Node.js, ripgrep, clang-tidy/clang-scan-deps, cppcheck. Состав проверяется скриптом `Development/AgentsRules/Scripts/Doctor.ps1`.

```powershell
# Из корня Epidemic, предпочтительно PowerShell 7
pwsh -NoProfile -File .\Development\AgentsRules\Scripts\Doctor.ps1

# Дополнительная установка/подготовка инструментов, осторожно:
# script may install system packages via winget, npm and Python environments
pwsh -NoProfile -File .\Development\AgentsRules\Scripts\Setup-AgentTools.ps1
```

`Setup-AgentTools.ps1` может изменять настройки `.codex/config.toml`, `.clangd`, `AGENTS.md` и `.gitignore`; перед запуском сравните несохранённые локальные изменения. Параметры `-SkipSystemInstall`, `-SkipRetrieval`, `-SkipClangdConfigure` представлены непосредственно в скрипте. Обычно одноразовой установки достаточно.

Папка `build/` предназначена для C++ продуктов. `.ai/` хранит генерируемые инструменты, logs, temporary и индексы. Доказательства выполненных запусков Auditor и защищённые product captures могут иметь собственные правила хранения: не удаляйте их как обычный cache без проверки.

## Проверка подготовленного окружения

Для репозитория используйте PowerShell 7 и CMake 3.25 или новее, совместимый C++23 compiler и соответствующие Windows SDK/MSVC components для Win32/D3D11. Для запуска workflow `Invoke-Dev.ps1` нужен установленный `Visual Studio 18 2026` generator; наличие другого Visual Studio не гарантирует выполнение этого скрипта. Python Auditor использует изолированный venv и установленный `psutil`; ETW/Verifier требуют отдельной подготовки.
