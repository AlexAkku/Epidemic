# Папки и артефакты

| Путь относительно корня | Содержимое / ownership |
| --- | --- |
| `EngineBase/` | Реализация process/platform/RHI foundations |
| `EngineRuntime/` | Runtime majors и Support |
| `EngineFramework/` | Gameplay owners и IntegrationLayer |
| `Documentation/` | Основная исходная документация и контракты |
| `Development/` | Правила агента, milestone планы и скрипты |
| `build/` | Продукты CMake, тестовые `.exe`, PDB, объектные файлы |
| `.ai/` | Локальный tooling runtime, logs, retrieval indexes, Auditor captures |
| `.epidemic-auditor/` | Исходники внешнего диагностического инструмента |
| `.github/workflows/` | CI задания в снимке |
| `Tests/Truth/` | Системные truth-тесты / fixture boundary |

Скрипты могут удалять disposable подкаталоги `.ai/`, но Auditor raw/product evidence может потребовать сохранения для воспроизводимости и истории. Перед очисткой выясните источник данных. Не добавляйте в Git большие индексы, бинарники или временные логи без явной политики.
