# Доработки после аудита Ascent — 21.10.2026

Исторические измерения: [Engine Audit 2026-10-21](<Reports/Archive/Engine Audit 2026-10-21.md>).
Приоритеты и номера относятся к этому отчёту. Новые тесты, сборки, игровые и
профилировочные прогоны после аудита не выполнялись по запросу владельца.

## Выполненные изменения кода

| Пункт | Изменение | Коммит |
|---|---|---|
| P1-1 | WebAudio: удаление live record, отключение source/gain/analyser, очистка media, monotonic handles и безопасный stale access | `2efe5df` |
| P1-2 | TLS guard до захвата recorder lock, в initialize/flush и context lookup; дешёвый подсчёт потерь после заполнения буфера | `16202ca` |
| P1-3 | Ограниченные по времени/размеру и отменяемые этапы xperf, progress.json и UI log, сохранение завершённых частичных отчётов | `ae89007` |
| P1-5 | Явно включённые out-of-tree source files в статическом/наблюдаемом графе; сторонние SDK остаются вне owned inventory | `041adc1` |
| P2-6 | Named current/legacy scenarios, content version, legacy opt-in; покадровый DEBUG только по запросу | `e6bf359`, `ebb2948`, `d971089`, `dac8ae7` |
| P2-7 | Reusable rig pivots/mirroring/anchors/preview, UI hit-testing/focus/localization, simulation/UI/media clock policy и пример | `5bba644` |

Это статусы реализации, **не подтверждение runtime-устранения** прежних симптомов.
В особенности для P1-2 установлен риск повторного входа, но первопричина
90-секундного таймаута не была доказана независимым стеком. Без прогона нельзя
объявлять exact-диагностику полностью работоспособной.

P1-4 исключён владельцем: путь установки/checkout — локальная интеграция клиента,
не дефект движка. CMake и Tools игрового проекта по этому пункту не менялись.
