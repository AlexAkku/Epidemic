# Числа в Graph: i64 и f64

Отправная точка:17498a7; расширение по замечаниям владельца19 ноября2026. Операции и время исполняет существующий C++ Graph VM/Runtime Scheduler. Java/JCEF отображают данные и отправляют команды.

Непомеченные Input/Add/Multiply/Output сохраняют i64. Варианты с пометкой f64 используют конечные IEEE754 double. Native/managed call ABI остаётся i64→i64; для соединения с ним нужны явные Convert i64 to f64 / Convert f64 to i64. Последнее преобразование отбрасывает дробную часть, отвергая значения вне диапазона i64. Смешанные порты без преобразования отклоняются.

Каталог `kNumericRecipes` в Runtime/Graph — единый источник новых TypeId, названий и операций. Game Schema регистрирует его, native catalogue проецирует в Palette/Rete. Java не содержит математической реализации или альтернативного каталога.

Добавлены Subtract, Divide и Integer Divide в обоих типах. Деление i64 отбрасывает дробную часть; Divide f64 сохраняет её. Integer Divide f64 возвращает целую часть частного в f64. Round Up/Down дают ceil/floor. Отдельный Round (0.6 up, f64) реализует именно порог, указанный владельцем:1.5→1,1.6→2,−1.6→−2; это явно подписанный режим, а не стандартный порог0.5.

На wire и в существующих default/settings сохраняются точные64 bits; тип задаётся PortDefinition.type_id. f64 кодируется bit_cast, а не числовым приведением к i64. Разбор текста, вычисления и проверки диапазона происходят в C++; UI форматирует полученное число. Формат GraphDefinition/DTO v5 и IPC envelope v4 не меняется. Новые значения Operation добавлены в конец enum; существующие значения и TypeId сохраняются. Instruction.value_type относится только к process-local IR. Старые графы не требуют миграции.

Inline literals, Input defaults, native Undo/Redo и Save/Open используют действующие команды/сериализацию. Оба пути VM — data и control flow — проверяют типы. NaN/Inf, деление на ноль и переполнение отклоняются; signed division MIN/−1 не вызывает UB. Отчёт Preview и runtime port values форматируются без обнуления малых дробей через to_chars.
